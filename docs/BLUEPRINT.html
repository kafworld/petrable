01Technology stack

The pieces, named plainly

Every layer is free-tier or owned infrastructure. Secrets live server-side only — the apps ship zero keys.

Client

SwiftUI · iOS 17+ / macOS

Targets Forge (iPhone) & KeithableMac → ships as Petrable. xcodegen project.yml is the project source of truth.

Backend

Convex (TypeScript)

Functions: projects · messages · builder · voice · models · freeAi router · system. Dev deployment focused-panther-579.

Inference

7 free providers

Gemini → Groq → NVIDIA → GitHub → OpenRouter → Cerebras → Cloudflare. Tiered fast / balanced / smart.

Web runtime

Daytona sandboxes

Managed API + per-sandbox toolbox proxy for exec/upload; preview URLs on daytonaproxy01.

iOS runtime

Mac Worker + Chorus

Local Xcode compiles → unsigned IPA / device install path; cloud builds repair compile errors.

Voice

Groq Whisper

Mic → text transcription server-side (free). No paid STT; OpenAI path removed with its dead key.

Quality

XCTest UI suite

6 end-to-end tests incl. prompt → live preview; evidence as xcresult bundles.

Signing

Apple team V892V3PC6T

Dev certs in keychain; automatic signing; Wi-Fi install over paired device FlyPhone17.

Docs

Markdown set + this hub

Blueprint · AGENTS runbook · Free-providers board · README — linked at the foot of this page.

05Workflows

How work actually moves

End-user build 
type prompt (+ optional mic → Groq STT)
 → projects.create {prompt, platform}
 → schedule builder.build
 → freeAi chain serves generation
 → files saved → Daytona sandbox
 → upload → server → preview probe
 → status=live → previewButton appears
 → tap → webview renders (asserted by ForgeDemoTest)
Model incident (live) 
provider 404/429 reported?
 → fetch provider /models catalogue
 → status-code matrix: tiny request × candidate
 → pin survivors in code + env
 → convex dev --once
 → re-run matrix after any provider incident
(never trust remembered model IDs)
Secret handling 
set:  npx convex env set NAME "$(security \
        find-generic-password -s svc -w)"
list: env list | cut -d= -f1     # names only
leak? → rotate that provider key immediately
rules: no secrets in output/docs/chat echoes
Device install (Wi-Fi) 
xcodebuild … -destination id=<udid> \
  DEVELOPMENT_TEAM=V892V3PC6T -allowProvisioningUpdates
 → devicectl device install app   # paired over Wi-Fi
 → locked screen blocks auto-launch (iOS policy)
 → launch after unlock, or tap the icon

07Troubleshooting playbook · case files

What broke, how we knew, what fixed it

1 · UI test failed with no useful message
SymptomXCTAssertTrue failed only.
MethodEvidence ladder: xcresult summary/tests → UI hierarchy → screenshots around window → reproduce ×3.
OutcomeFlaky timing test isolated to a sleep-vs-appearance race; fixed waits, 3/3 green. Never weaken assertions.
2 · App showed “Claude is designing your app” (string not in source)
SymptomStatus text absent from every repo file.
MethodThree-homes audit: client build ⇄ deployed backend ⇄ stored row. Grepped source, then all 23 DB rows.
OutcomeStale deployment/build — not code. Fresh builds said “Free AI is designing your app”. Always date the screenshot first.
3 · Every model suddenly 404
SymptomGemini 2.5 retired · Groq llama retired · OpenRouter :free slugs removed.
MethodFetch live catalogues; run a status-code matrix (tiny request per candidate); pin survivors; keep the chain.
OutcomeModel IDs are config, not constants — drift degrades to the next provider instead of an outage.
4 · Daytona404 “Cannot POST” (blocked every build)
SymptomOwner’s original screenshot: dead execute route — independent of model keys.
MethodVendor OpenAPI → discovered toolbox-proxy-url; llms.txt for map; npm pack the official SDK and grep basePath/auth.
OutcomeNew contract {proxy}/{sandboxId}/process/execute + Bearer → builds reached status: live. SDK source > blog posts.
5 · Secrets printed by an unfiltered env list
SymptomSix key values landed in tool output.
MethodImmediately rotated the non-owner-pasted keys (GitHub/Daytona/NVIDIA); new rule: env list | cut -d= -f1.
OutcomeHygiene baked into docs; keychain piping pattern documented.
6 · Volume degraded to multi-second reads
SymptomBuilds starved; processes in UN state; root ls hung >45 s.
MethodLatency matrix per volume (1ms / 9ms / 1–27s) → root readdir vs deep stat probe → found a pathological entry → ruled out Spotlight/Time Machine → bounded live fsck (clean).
OutcomePhysical-layer fault (cable/port) — stopped bulk jobs, continued read-only per storage standing order, reported with evidence.
7 · Convex deploy went to the wrong deployment
Symptomconvex deploy targeted prod and refused non-interactive prompting.
MethodRead CLI help; confirmed configured deployment; used convex dev --once for dev pushes.
OutcomeRule recorded: env commands default to dev, deploy defaults to prod — always confirm target.
8 · Howler stack-overflow spam (web preview)
Symptom148× RangeError: Maximum call stack from audio queue after registering sounds at boot.
MethodA/B control: disable one feature (barks) → 0 spam; enable → 148. Isolate registration timing vs audio unlock.
OutcomeRegister sounds only after audio.initiated (same as ambients) → 0 spam, playback verified.

10Golden rules

Pin these above the desk

1 — Free-only. Forever.

No paid fallback. One key works; zero keys drops the provider, never the product.

2 — Evidence before edits

xcresult → hierarchy → screenshots → reproduce ×3. Fix root causes, never assertions.

3 — Live probes over memory

Third-party routes, model IDs, quotas: verify with real requests before trusting them.

4 — Secrets never in output

Names-only listings; keychain piping; rotate the moment anything leaks.

5 — project.yml is truth

Hand-edited pbxproj vanishes on the next xcodegen run — edit the yml.

6 — Names matter

Petrable to the world; match the KAF family voice, brand tokens and care in presentation.
